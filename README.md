🐔 El Polo Loco – Keyboard & Mobile Reaction Game
A fast, chaotic, browser‑based reaction game built with HTML, CSS, and JavaScript.
Control the chicken using keyboard inputs (desktop) or touch controls (mobile) and try to survive as long as possible while collecting points.

This project focuses on smooth controls, responsive UI, and simple but addictive gameplay.

🎮 Features
🕹️ Keyboard Controls (Desktop)
Move the chicken using assigned keys

Responsive and fast input handling

No mouse required

📱 Mobile Controls
On‑screen touch buttons

Optimized layout for mobile screens

Same gameplay experience as desktop

🐔 Gameplay
Control the chicken and avoid obstacles 

Smooth animations and sound effects

Simple, fast, chaotic fun

🔊 Audio
Sound effects for actions

Optional mute toggle 

🛠️ Tech Stack
Layer	Technology
Frontend	HTML, CSS, JavaScript
Storage	localStorage
Assets	Custom images & sounds
Controls	Keyboard + Touch UI
